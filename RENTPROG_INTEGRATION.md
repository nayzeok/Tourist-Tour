# Интеграция RentProg — модуль аренды авто

## Обзор

[RentProg](https://rentprog.ru) — CRM-система для управления прокатом автомобилей. API и виджет формы бронирования позволяют интегрировать аренду авто на сайт Турист-Тур.

## Ресурсы RentProg

| Ресурс | URL | Описание |
|--------|-----|----------|
| **Swagger API** | https://rentprog.ru/swagger.html | Документация API для разработчиков |
| **Личный кабинет** | https://web.rentprog.ru/signin | Вход в систему RentProg |
| **Центр помощи** | https://rentprog.ru/ru/helpcenter | Документация, руководства |
| **Виджет на сайт** | https://rentprog.ru/ru/widget | Форма бронирования для встраивания |
| **Инструкция виджета** | https://rentprog.ru/ru/categories/8/guides/34 | Подробная настройка формы |

## Варианты интеграции

### 1. Виджет (рекомендуется на старте)

Форма бронирования встраивается через веб-компонент `<rentprog-widget>`. Клиенты видят свободные автомобили, расчёт стоимости и отправляют заявки. Заявки попадают в RentProg.

**Подключение:**
- CSS: `https://rentprog-b5205.web.app/css/app.css`
- JS: `https://rentprog-b5205.web.app/js/app.js`

**Где взять API токен:** Профиль компании → вкладка «Компания» → API токен (клик копирует в буфер).

### 2. REST API (для глубокой интеграции)

Swagger: https://rentprog.ru/swagger.html  

Позволяет работать с:
- бронированиями
- клиентами
- данными об автомобилях
- поиском и доступностью

## Реализовано в проекте

### Frontend

- **Страница:** `/rent` — аренда автомобилей
- **Виджет:** `RentProgWidget.vue` — встраивание формы RentProg
- **Footer:** Ссылка «Прокат автомобилей» → `/rent`

### Конфигурация

В `.env` или переменных окружения:

```env
# RentProg (виджет аренды авто)
NUXT_PUBLIC_RENTPROG_TOKEN=your_api_token_here
```

Токен берётся в [Профиле компании RentProg](https://web.rentprog.ru/signin) → Компания → API токен.

## Параметры виджета RentProg

| Параметр | Описание | Пример |
|----------|----------|--------|
| `token` | API токен компании | Обязательно |
| `locale` | Язык (ru, en, de, ...) | `ru` |
| `show_all_cars` | Показывать все авто / только свободные | `false` |
| `car_id` | ID конкретного авто (опционально) | — |
| `car_name` | Название авто при использовании car_id | — |
| `show_email` | Поле email | `true` / `false` |
| `show_phone` | Поле телефона | `true` |
| `show_middlename` | Поле отчества | `false` |
| `show_birthday` | Дата рождения | `false` |
| `show_passport` | Паспорт | `false` |
| `show_address` | Адрес | `false` |
| `show_driver_license` | Водительское удостоверение | `true` |
| `rental_object` | Текст вместо «Выбрать автомобиль» | «Выберите авто» |
| `hidden_car_year` | Скрыть год выпуска | `false` |
| `places` | Места выдачи/приёма и цены | JSON |
| `equipment` | Доп. оборудование | JSON |
| `chairs` | Детские кресла | JSON |
| `boosters` | Бустеры | JSON |
| `agreement` | Ссылка на условия аренды | JSON |
| `button_classes` | CSS-классы кнопок | Tailwind v2 |
| `yandex_metrika_id` | ID счётчика Метрики | Для целей |

Подробнее: [Инструкция виджета](https://rentprog.ru/ru/categories/8/guides/34)

## Следующие шаги (фаза 2)

1. **Получить API токен** в RentProg и прописать в `NUXT_PUBLIC_RENTPROG_TOKEN`.
2. **Проверить работу виджета** на странице `/rent`.
3. **API-интеграция** (по необходимости):
   - эндпоинты бэкенда для поиска/бронирования
   - синхронизация с личным кабинетом и бронированиями
4. **Бронирования в ЛК** — отображение аренды авто вместе с отелями и авиабилетами.
